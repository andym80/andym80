## What I'm building

**OMNI** is my main project: generative AI for sound, on stage and in installations. In 2024 it was selected for the a16z × Buildspace six-week builder program, one of 300 projects out of 32,000 applications. It has grown into a small family of tools:

- **OMNI Console** — a TypeScript [MCP](https://modelcontextprotocol.io) server that connects Claude to Ableton Live. You describe what you want and it sets tempo, creates tracks, loads devices, writes MIDI clips and fires scenes. Includes input validation, an HTTP bridge and a dashboard.
- **OMNI Remote** — a phone-sized PWA (Next.js) that turns any phone on the same WiFi into a session controller for Live: clip launcher, mixer, transport and setlists, pushed in real time over WebSocket, with Ableton Link tempo sync.
- **MPC Controller MCP** — an MCP server that drives an Akai MPC Live II over USB MIDI from Claude.

Other things on my desk:

- **HandSonic HPD-20 editor** — a web editor for the Roland HandSonic HPD-20, with WAV editing and USB export in progress.
- **Alquiler por m²** — rent per square metre across Buenos Aires neighbourhoods on a map, with a link to every listing. Next.js, PostgreSQL + PostGIS, Leaflet.
- **[Task Manager](https://github.com/andym80/TasksRailsApi)** — Rails 8 API with a Next.js 16 front end, PostgreSQL and Docker Compose.

Most of the OMNI code lives in private repositories while it is in development. I'm happy to walk through it on a call.
